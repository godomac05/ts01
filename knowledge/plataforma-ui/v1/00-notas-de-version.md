# Interfaz de la plataforma — versión v1

## Sobre esta versión

Esta carpeta documenta la interfaz y los procesos de la plataforma tal como
se ven en **agosto de 2026**. Si la plataforma cambia mucho de diseño más
adelante, esta versión se conserva tal cual y el contenido nuevo se agrega en
una carpeta `v2/` (ver `../README.md` para el procedimiento).

Todavía no se ha agregado contenido específico de pantallas — se irá
completando conforme se compartan capturas de la plataforma.
